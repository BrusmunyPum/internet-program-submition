# Library App

Week 3 Part E practice: a small Vue app for borrowing books from a library, on hard-coded data.

```bash
cd frontend
npm install
npm run dev        # open http://localhost:5173
npm run test:unit  # BookCard tests (Vitest)
npm run lint       # ESLint
```

- `docs/wireframes/`: wireframes of the main screens
- `docs/components.md`: component tree, props, events, and who owns the state
- `frontend/src/types.ts` and `frontend/src/data/`: the `Book` type and the sample books
